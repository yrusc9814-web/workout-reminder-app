# VAN-23 备份文本渲染说明

备份导入仍按现有流程解析、校验并写入后端；标题、动作名称、规格、备注、方案 ID 等业务字段保持原始文本语义。导入确认前只显示固定模板与数量摘要，校验错误也通过 `textContent` 写入提示节点。

正式首页的周计划、月日历、今日进度与清单、训练方案、日期详情/调整和未来日期安排路径使用 `createElement`、`textContent`、`createTextNode` 及明确的 `setAttribute` 写入动态值。固定的产品文案和内置调整建议可以继续使用受控模板。这样 HTML 只负责产品自身结构，备份文本不会被解析成元素或事件属性，也不会因为提前编码而在存储和回读时发生双重编码。
