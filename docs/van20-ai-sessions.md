# AI 会话归属与归档恢复

轻动日记把每次 AI 请求绑定到发送时所在的会话。切换到其他会话不会改变已发请求的归属；成功回复和失败 fallback 都会回到原会话。原会话被归档时，请求不会被取消，只要会话仍存在，返回内容仍会写回该会话；会话被删除后，late response 会被丢弃。

同一会话同时只允许一个 AI 请求。发送按钮、Enter 和快捷问题都遵守这个限制。不同会话可以并行请求；切换会话时，发送按钮只反映当前会话的 pending 状态。pending 状态只存在于当前页面运行时，不会写入工作区，刷新后不会伪造 loading。

归档会话仍保留原来的 id、标题、创建时间和消息。进入「设置 → 归档项目与会话」可以找到已归档会话，点击「恢复会话」会将原会话恢复到「未分类」并立即保存。恢复不会复制会话，刷新页面后仍使用同一个会话 id 和完整消息记录。

工作区使用 `qd-ai-workspace-v2` 保存。页面启动时会把 current session 归一化到可见、未归档的会话；如果当前会话不可用，会选择首个有效会话，没有可用会话时创建新的未分类空会话。旧 v1 会话仍从 `qd-sessions-v1` 迁移，迁移失败时只有用户明确选择重试或进入空工作区才会改变工作区数据。
